# 🚀 快速开始指南

> 5 分钟从 0 到 1，开始你的 B站 AI 自动运营之旅

---

## 📦 第一步：克隆项目

```bash
# 克隆仓库
git clone https://github.com/lb290/bilibili-ai-research.git
cd bilibili-ai-research

# 创建虚拟环境
python3 -m venv .venv
source .venv/bin/activate  # Linux/Mac
# .venv\Scripts\activate   # Windows
```

---

## 📦 第二步：安装依赖

```bash
# 安装 Python 依赖
pip install rich pydantic python-dotenv aiohttp httpx openai edge-tts

# 安装 bili-cli（可选，需要网络）
pip install bili-agent
```

---

## 🎭 第三步：配置人设

```bash
# 编辑人设文件
nano config/persona.json

# 或使用预设的龙娘小夏人设
# 文件已包含完整配置
```

**关键配置项**：
- `name`: 角色名
- `personality.catchphrase`: 口头禅
- `interaction.response_rules`: 回复规则
- `visual`: 视觉形象

---

## 🔑 第四步：配置 API

```bash
# 复制环境变量模板
cp config/.env.example .env

# 编辑环境变量
nano .env
```

**必填项**：
```
DEEPSEEK_API_KEY=your-api-key
```

**获取 API Key**：
1. 访问 https://platform.deepseek.com
2. 注册账号
3. 创建 API Key
4. 复制到 .env 文件

---

## 🧪 第五步：测试

```bash
# 运行人设测试
python scripts/test_persona.py

# 运行功能演示
python -c "from bili_ai.cli import main; main()" demo
```

---

## 🎬 第六步：创建第一个视频

### 方法 A：使用预设脚本

```bash
# 查看预设脚本
cat output/video_script.json

# 生成视频（需要 bili-cli）
python -m bili_ai generate --script output/video_script.json
```

### 方法 B：创建新脚本

```bash
# 创建脚本文件
cat > my_script.json << 'EOF'
{
  "title": "我的第一个 AI 视频",
  "content": "大家好，这是我的第一个 AI 生成视频！",
  "tags": ["AI", "测试"]
}
EOF

# 生成视频
python -m bili_ai generate --script my_script.json
```

---

## 📤 第七步：投稿到 B站

```bash
# 投稿视频
bili upload video \
    --file output/demo.mp4 \
    --title "【Day 0】我的第一个 AI 视频" \
    --tags "AI,测试" \
    --description "本视频由 AI 辅助生成"
```

---

## 💬 第八步：开始运营

```bash
# 查看收件箱
bili-ai inbox

# 回复评论
bili-ai reply 12345 "谢谢支持！～" --at

# 发动态
bili-ai post "新视频发布啦！"

# 查看数据
bili-ai stats --account
```

## ⚠️ 常见问题

### Q: bili-cli 安装失败怎么办？
A: 检查网络连接，或使用代理：
```bash
pip install --proxy http://your-proxy:port bili-agent
```

### Q: API Key 无效？
A: 检查 .env 文件中的 API Key 是否正确，确保有足够余额

### Q: 视频生成失败？
A: 检查脚本文件格式是否正确，确保有输出目录

### Q: 评论被折叠？
A: 检查敏感词配置，避免包含敏感内容
