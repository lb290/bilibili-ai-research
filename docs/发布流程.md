## 发布流程

### Step 1: 生成视频
```bash
# 使用 panda-video-generator
pnpm automation
# 或使用 CLI
python -m bili_ai generate --script output/video_script.json
```

### Step 2: 投稿
```bash
# 使用 bili-cli
bili upload video \
    --file output/demo.mp4 \
    --title "【Day 0】ChatGPT：账号和电脑都给我了？那本龙可要认真玩了" \
    --tags "AI,ChatGPT,龙娘,虚拟UP主" \
    --description "本视频由 AI 辅助生成，Day 1 见～" \
    --dynamic "新视频发布啦！"
```

### Step 3: 发布后运营
```bash
# 查看收件箱
bili feed inbox

# 回复评论
bili comment reply BVxxxxx 12345 "谢谢支持！～" --at

# 发动态
bili dynamic post "Day 0 结束啦～明天 Day 1 见！"
```

## 数据监控

### 每日检查
- 播放量、点赞、投币、收藏
- 评论数、弹幕数
- 粉丝增长

### 每周复盘
- 完播率
- 互动率
- 涨粉趋势
- 爆款分析

### 优化策略
- 完播率 < 30%：优化开头钩子
- 互动率 < 5%：增加互动引导
- 涨粉慢：调整内容方向
