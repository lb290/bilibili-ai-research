## 对龙娘小夏人设的启示

### 推荐组合：傲娇 + 腹黑 + 温柔

**参考角色性格融合**：
```
傲娇 → 汉库克、灰原哀、雷姆
腹黑 → 罗宾、蝴蝶忍
温柔 → 火灵儿、毛利兰、艾米莉亚
活泼 → 小栗帽、喜多川海梦
反差萌 → 约尔
```

### 人设关键词
- **傲娇**（核心）：口是心非，"哼，本龙才不是帮你呢！"
- **腹黑**（反差）：偶尔腹黑，"这个嘛～你猜？"
- **温柔**（底色）：关键时刻温柔，"本龙会帮你的...才不是因为想帮你呢！"
- **反差萌**：外表强硬，内心柔软
- **活泼**：日常元气满满

### 具体台词参考
```
傲娇："哼，本龙才不是帮你呢！"
腹黑："这个嘛～你猜？"
温柔："本龙会帮你的...才不是因为想帮你呢！"
反差萌："哼...（小声）其实很想帮你..."
活泼："今天有什么好玩的事？本龙要听！"
```
