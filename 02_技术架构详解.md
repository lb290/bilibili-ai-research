## 二、核心模块详解

### 2.1 账号登录与认证

#### 扫码登录流程

```
1. 请求登录二维码
   GET https://passport.bilibili.com/x/passport-login/web/qrcode/generate
   ↓
2. 返回二维码 URL + 登录密钥 (oauthKey)
   {
     "data": {
       "url": "https://passport.bilibili.com/qrcode/xxx",
       "oauthKey": "abc123"
     }
   }
   ↓
3. 轮询登录状态
   GET https://passport.bilibili.com/x/passport-login/web/qrcode/poll?oauthKey=abc123
   ↓
4. 返回结果：
   - 0: 扫码成功，返回 cookies
   - 86090: 未扫码
   - 86083: 二维码已失效
   ↓
5. 保存 cookies 到本地文件
   ~/.config/bili-cli/cookies.json
```

#### Cookie 管理

```python
# bili-cli 的 cookie 存储结构
{
  "dedeuserid": "12345678",
  "sessdata": "abc123...",
  "bili_jct": "def456...",
  "expires": 1700000000,
  "refresh_token": "xyz789..."
}
```

**关键点：**
- `sessdata`: 核心认证凭证，用于所有写操作
- `bili_jct`: CSRF token，防止跨站请求伪造
- `dedeuserid`: 用户 ID

#### 评论回复流程

```python
# bili-cli 的评论回复逻辑
async def reply_to_comments():
    # 1. 获取未回复的评论
    comments = await bili.comment.list(
        bv_id="BV1GJ411x7h7",
        unreplied=True  # 只看没回过的
    )
    
    for comment in comments:
        # 2. 用 LLM 生成回复
        reply = await llm.generate(
            context=f"粉丝评论: {comment['content']}",
            persona=persona_config,
            style="友好、幽默、简洁"
        )
        
        # 3. 发送回复
        result = await bili.comment.reply(
            bv_id="BV1GJ411x7h7",
            parent_id=comment['id'],
            content=reply,
            at=comment['user']['uid']  # 真正的 @ 提醒
        )
        
        # 4. 记录审计日志
        audit_log.write(f"回复评论: {comment['id']} -> {reply}")
```

## 三、限流与风控机制

### 3.1 bili-cli 的限流策略

```python
# 限流配置
RATE_LIMITS = {
    "comment_post": {"interval": 10, "hourly": 30},   # 评论：10秒/次，30次/小时
    "dm_send": {"interval": 10, "hourly": 20},        # 私信：10秒/次，20次/小时
    "dynamic_post": {"interval": 60, "hourly": 10},   # 动态：60秒/次，10次/小时
    "upload_video": {"interval": 300, "daily": 2},    # 投稿：5分钟/次，每天2次
    "coin": {"daily": 5},                              # 投币：每天最多5个
}
```

### 3.2 B站风控触发条件

| 行为 | 触发条件 | 后果 |
|------|---------|------|
| 评论过快 | 1分钟内超过5条 | 验证码/评论限制 |
| 私信过快 | 1分钟内超过3条 | 私信功能限制 |
| 投稿过快 | 1小时内超过2条 | 审核延迟/限制 |
| 新号操作 | 注册7天内 | 全功能限制 |
| IP 异常 | 多账号同 IP | 全部风控 |
| 内容异常 | AI 生成未标注 | 限流/封禁 |

### 3.3 应对策略

```python
# bili-cli 的风控处理
async def safe_operation(operation, *args, **kwargs):
    try:
        result = await operation(*args, **kwargs)
        return result
    except RiskControlError as e:
        # 遇到风控立刻停止
        audit_log.write(f"风控触发: {e.code}, 停止操作")
        notify_owner(f"⚠️ 风控触发: {e.message}")
        raise
    except CaptchaRequiredError as e:
        # 需要人工验证
        audit_log.write(f"验证码: {e.image_url}")
        notify_owner("请处理验证码")
        raise
    except RateLimitedError as e:
        # 等待限流恢复
        wait_time = e.retry_after
        audit_log.write(f"限流: 等待 {wait_time} 秒")
        await asyncio.sleep(wait_time)
        return await operation(*args, **kwargs)
```

### 8.2 常见坑与解决方案

#### 坑 1：Cookie 过期

**现象**：登录后一段时间，API 返回 -101 或 -403

**原因**：B站 Cookie 有效期约 7 天，过期后需要重新扫码

**解决方案**：
```python
# 自动刷新 Cookie
async def refresh_cookie():
    try:
        result = await bili.auth.status()
        if result['code'] == -101:
            print("Cookie 过期，需要重新登录")
            # 发送通知给主人
            await notify_owner("Cookie 过期，请重新扫码登录")
            return False
    except Exception as e:
        print(f"检查登录状态失败: {e}")
        return False

# 定时检查
import schedule
schedule.every().day.at("08:00").do(refresh_cookie)
```

#### 坑 2：视频上传失败

**现象**：上传视频时返回错误或卡住

**常见原因**：
- 文件大小超过限制（B站最大 16GB）
- 视频格式不支持（推荐 MP4/H.264）
- 网络中断
- 审核失败

**解决方案**：
```python
async def upload_with_retry(video_path, title, max_retries=3):
    for attempt in range(max_retries):
        try:
            result = await bili.upload.video(
                file=video_path,
                title=title,
                tags=["AI", "科技"],
                desc="本视频由 AI 生成"
            )
            return result
        except UploadError as e:
            if e.code == -122:  # 审核失败
                print(f"审核失败: {e.message}")
                # 修改后重试
                await fix_video(video_path)
            elif e.code == -600:  # 风控
                print("风控触发，停止上传")
                break
            else:
                print(f"上传失败，第 {attempt+1} 次重试")
                await asyncio.sleep(60)
    
    return None
```

#### 坑 3：评论被折叠

**现象**：评论发送成功，但被系统折叠，粉丝看不到

**原因**：
- 新号评论
- 评论内容含敏感词
- 评论频率过快

**解决方案**：
```python
async def safe_comment(bv_id, content):
    # 1. 检查评论内容
    if contains_sensitive_word(content):
        print("评论含敏感词，跳过")
        return False
    
    # 2. 发送评论
    result = await bili.comment.post(bv_id, content)
    
    # 3. 检查是否被折叠
    check_result = await bili.comment.check(bv_id, result['id'])
    if check_result['status'] == 'hidden':
        print("评论被折叠，修改后重试")
        # 简化内容重试
        simple_content = simplify_content(content)
        return await safe_comment(bv_id, simple_content)
    
    return True
```

#### 坑 4：Playwright 自动化上传失败

**现象**：浏览器自动化上传时失败

**常见原因**：
- 页面元素变化（B站改版）
- 网络超时
- 文件路径错误

**解决方案**：
```python
async def auto_upload_with_playwright(video_path):
    from playwright.async_api import async_playwright
    
    async with async_playwright() as p:
        browser = await p.chromium.launch(headless=False)
        page = await browser.new_page()
        
        # 设置超时
        page.set_default_timeout(60000)
        
        try:
            # 登录
            await page.goto("https://member.bilibili.com/v2/upload")
            
            # 等待页面加载
            await page.wait_for_selector('.upload-input', timeout=30000)
            
            # 上传文件
            await page.set_input_files('.upload-input', video_path)
            
            # 等待上传完成
            await page.wait_for_selector('.upload-success', timeout=300000)
            
            print("上传成功")
            
        except TimeoutError:
            print("页面加载超时，检查网络")
            # 截图保存
            await page.screenshot(path='error.png')
        except Exception as e:
            print(f"上传失败: {e}")
            await page.screenshot(path='error.png')
        finally:
            await browser.close()
```

    while True:

        memory = psutil.virtual_memory()
