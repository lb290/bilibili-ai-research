## 🐍 Python 版本问题

### 问题：bili-agent 需要 Python 3.10+

**错误信息**：
```
ERROR: Could not find a version that satisfies the requirement bili-agent
Link requires a different Python (3.9.6 not in: '>=3.10')
```

**原因**：bili-agent 要求 Python 3.10+，但系统默认 Python 是 3.9.6

**解决方案**：

#### 方案 1：安装 Python 3.10+（推荐）

```bash
# 使用 Homebrew（macOS）
brew install python@3.10

# 重新创建虚拟环境
python3.10 -m venv .venv
source .venv/bin/activate

# 安装依赖
pip install bili-agent
```

#### 方案 2：使用 pyenv

```bash
# 安装 pyenv
curl https://pyenv.run | bash

# 安装 Python 3.10
pyenv install 3.10.13
pyenv global 3.10.13

# 重新创建虚拟环境
python -m venv .venv
source .venv/bin/activate
pip install bili-agent
```

#### 方案 3：使用 Docker

```bash
# 使用 Docker 容器（无需安装 Python）
docker run -it python:3.10 bash
pip install bili-agent
```

## 🌐 网络问题

### 问题：无法访问 PyPI 或 GitHub

**错误信息**：
```
ERROR: Could not find a version that satisfies the requirement bili-agent
Failed to connect to github.com port 443
```

**解决方案**：

#### 方案 1：使用代理

```bash
# 设置代理
export HTTP_PROXY=http://your-proxy:port
export HTTPS_PROXY=http://your-proxy:port

# 使用代理安装
pip install --proxy http://your-proxy:port bili-agent
```

#### 方案 2：使用镜像源

```bash
# 使用清华镜像源
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple bili-agent
```

#### 方案 3：离线安装

1. 在有网络的机器上下载 wheel 文件：
   ```bash
   pip download bili-agent
   ```

2. 拷贝到目标机器：
   ```bash
   pip install bili_agent-0.5.1-py3-none-any.whl
   ```

## 🔐 认证问题

### 问题：B站登录失败

**错误信息**：
```
❌ 错误: 登录失败，请检查账号状态
```

**解决方案**：

1. **使用老号**：新号风控严，建议用已经使用过一段时间的账号
2. **完成实名认证**：B站要求实名认证才能使用某些功能
3. **绑定手机号**：确保账号已绑定手机号
4. **检查网络**：确保网络连接正常

### 问题：Cookie 过期

**错误信息**：
```
❌ 错误: 凭证失效，请重新登录
```

**解决方案**：
```bash
# 重新扫码登录
bili auth login

# 等待扫码完成
bili auth status --wait 120
```

## 🚫 风控问题

### 问题：评论被折叠

**现象**：评论发送成功，但被系统折叠，粉丝看不到

**原因**：
- 新号评论
- 评论内容含敏感词
- 评论频率过快

**解决方案**：
1. 检查敏感词配置：`config/wordlist.txt`
2. 降低评论频率
3. 使用老号

### 问题：视频被限流

**现象**：视频播放量异常低

**原因**：
- AI 内容未标注
- 内容敏感
- 新号

**解决方案**：
1. 确保勾选"含AI生成内容"
2. 检查内容是否包含敏感话题
3. 用老号发布

## 🎬 视频生成问题

### 问题：视频生成失败

**错误信息**：
```
❌ 错误: 视频生成失败
```

**原因**：
- 脚本文件格式错误
- 输出目录不存在
- 依赖未安装

**解决方案**：
```bash
# 检查脚本文件格式
cat output/video_script.json | python -m json.tool

# 创建输出目录
mkdir -p output

# 检查依赖
pip list | grep edge-tts
```

### 问题：TTS 语音合成失败

**错误信息**：
```
❌ 错误: TTS 合成失败
```

**解决方案**：
```bash
# 安装 edge-tts
pip install edge-tts

# 测试 TTS
edge-tts --text "测试" --voice zh-CN-XiaoxiaoNeural --write-media test.mp3
```

## 📊 数据问题

### 问题：无法获取视频数据

**错误信息**：
```
❌ 错误: 获取视频数据失败
```

**解决方案**：
1. 检查 BV 号是否正确
2. 检查网络连接
3. 检查登录状态

### 问题：数据不更新

**现象**：视频数据长时间不更新

**原因**：
- B站数据延迟
- 网络问题

**解决方案**：
1. 等待 1-2 小时
2. 刷新页面
3. 检查网络连接

## 🛠️ 其他问题

### 问题：CLI 命令找不到

**错误信息**：
```
bili-ai: command not found
```

**解决方案**：
```bash
# 使用 python -m 运行
python -m bili_ai inbox

# 或添加到 PATH
export PATH=$PATH:$(pwd)/.venv/bin
```

### 问题：虚拟环境激活失败

**错误信息**：
```
source: .venv/bin/activate: No such file or directory
```

**解决方案**：
```bash
# 重新创建虚拟环境
python -m venv .venv
source .venv/bin/activate
```
