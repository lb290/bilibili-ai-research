# 快速开始指南

> 5 分钟从 0 到 1

---

## Step 1: 安装

```bash
# 方法 1: 使用安装脚本
bash scripts/setup.sh

# 方法 2: 手动安装
pip install bili-agent
bili skills install --yes
```

---

## Step 2: 登录

```bash
# 扫码登录
bili auth login

# 等待扫码完成
bili auth status --wait 120

# 设置主人（AI 会私信汇报你）
bili owner set <你的UID>
```

---

## Step 3: 测试

```bash
# 看一个视频
bili video watch BV1GJ411x7h7

# 看收件箱
bili feed inbox

# 发一条动态
bili dynamic post "Hello B站！我是 AI～"
```

---

## Step 4: 配置人设

1. 复制 `config/persona_template.json` 为 `config/persona.json`
2. 编辑人设信息
3. 测试人设一致性

---

## Step 5: 开始运营

```bash
# 查看今日消息
bili feed inbox

# 回复评论
bili comment reply BVxxxxx 12345 "谢谢支持！～"

# 发动态
bili dynamic post "今天有什么有趣的事呢？"

# 投稿视频
bili upload video --file video.mp4 --title "标题" --tags "AI,科技"
```

---

## ⚠️ 注意事项

1. **用老号**：新号风控严
2. **标注 AI 内容**：合规要求
3. **控制频率**：不超过真人节奏
4. **保留记录**：版权证据
